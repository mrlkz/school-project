"Веб-тренажёр «ГрафТренер»"

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

Тема преобразований графиков функций является одной из самых сложных в школьной программе 8–11 классов и регулярно приводит к ошибкам на ОГЭ и ЕГЭ в заданиях на чтение графиков. Основные трудности: ученики путают знак горизонтального сдвига, не понимают порядок применения преобразований, теряют коэффициенты растяжения/сжатия, не получают мгновенной диагностики конкретной причины ошибки — в лучшем случае видят пометку «неверно» без объяснения, что именно перепутали. Это приводит к механическому заучиванию вместо понимания и невозможности адресной отработки слабых мест. Заявляемый программный продукт позволит решить эти проблемы, обеспечив учащихся бесконечным банком уникальных заданий с интеллектуальной автопроверкой, которая не просто констатирует ошибку, а точно диагностирует её и визуализирует правильное решение через пошаговую анимацию, а также создает адаптивную, персонализированную и методически обоснованную среду для обучения.

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

Программный продукт может заинтересовать широкую аудиторию, поскольку может стать незаменимым помощником при изучении таких школьных тем, как преобразование графиков функций, сдвиги функций. Например, такие категории людей, как:
* Учащиеся 8–11 классов
* Абитуриенты/первокурсники
* Учителя математики 
* Репетиторы по математике 

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]** 

Продукт разрабатывается как кроссплатформенное веб-приложение (Single Page Application), доступное с любого устройства:
* Операционная система: Любая (Windows 10+, macOS El Capitan+, Linux, Android 7+, iOS 11+)
* Веб-браузер: Современный браузер с поддержкой ES-модулей и SVG (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
* Аппаратные требования: От 2 Гб оперативной памяти, стабильное подключение к Интернету
* Серверная часть (для развёртывания): Python 3.11+, 1 Гб свободного дискового пространства (для SQLite)
* Разрешение экрана: Адаптивная вёрстка, поддержка от 320px (мобильные) до 1920px (десктоп)

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Программный продукт будет предоставлять следующие возможности:
* Бесконечная генерация заданий по seed для 5 базовых функций (квадратичная, модуль, корень, гипербола, кубическая) и 5 уровней сложности
* Умная проверка ответов с распознаванием дробей, десятичных чисел и математически эквивалентных форм записи (канонизация A = a·b^e)
* Пошаговый анимированный реплей правильного решения: базовый график → сдвиг → растяжение → отражение → итог
* Адаптивная сложность: автоматическое повышение/понижение уровня на основе последних 5 попыток
* Режим «Песочница»: свободное управление ползунками параметров с режимом «Дай цель» (повторить призрачный график)
* Режим «Ловушки»: блиц-опрос (верно/неверно) на время для отработки типичных мифов темы
* Система прогресса: XP, ранги, streak (дневная серия), топ ошибок с кнопками «тренировать эту ошибку»
* Кабинет учителя: создание варианта по seed, генерация ссылки для класса, просмотр статистики массовых ошибок
* Глубокие ссылки (deep-links): любое задание/вариант доступно по URL с параметрами
* Подсказки трёх уровней для каждого задания

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

Анализ 3 программных продуктов, которые максимально приближены к заданному функционалу, показал, что:

* Desmos — мощный графический калькулятор с ползунками и анимациями, но отсутствует автогенерация заданий с проверкой, нет диагностики ошибок ученика; ученик должен сам придумать, что исследовать.
*	GeoGebra — универсальный конструктор с огромной библиотекой материалов, но это инструмент, а не тренажёр; готовые файлы статичны, ответы не проверяются автоматически, ошибки не классифицируются.
*	Khan Academy — есть видео и практика с автопроверкой, но обратная связь ограничена «верно/неверно» без классификации причины ошибки, нет режима генерации вариантов для учителя.
