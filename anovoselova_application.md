"Веб-тренажёр «ГрафТренер»"

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

Тема преобразований графиков функций является одной из самых сложных в школьной программе 8–11 классов и регулярно приводит к ошибкам на ОГЭ и ЕГЭ в заданиях на чтение графиков. Основные трудности: ученики путают знак горизонтального сдвига, не понимают порядок применения преобразований, теряют коэффициенты растяжения/сжатия, не получают мгновенного разбора конкретной причины ошибки – в лучшем случае видят пометку «неверно» без объяснения, что именно перепутали. Это приводит к механическому заучиванию вместо понимания и невозможности адресной отработки слабых мест. Данный проект позволит решить эти проблемы, обеспечив учащихся бесконечным банком уникальных заданий с автопроверкой, которая не просто выявляет ошибку, а точно указывает на неё и визуализирует правильное решение через пошаговую анимацию, а также создает адаптивную, простую и понятную среду для обучения. 
Будут проведены опросы среди целевой аудитории с целью выяснения актуальности этой проблемы, а также проанализированы результаты самостоятельных работ учеников 8-11 классов по этой теме.

**[ ЗАКАЗЧИК / ЦЕЛЕВАЯ АУДИТОРИЯ ]**

Проект может заинтересовать широкую аудиторию, поскольку может стать незаменимым помощником при изучении таких школьных тем, как преобразование графиков функций, сдвиги функций. Среди пользователей могут быть следующие категории людей:
* Учащиеся 8–11 классов, которые не понимают или понимают с трудом тему функций
* Абитуриенты/первокурсники, которые хотят повторить эту тему для продолжения обучения после школы
* Учителя математики, которые хотят качественные готовые наборы задач под конкретные темы и уровни
* Репетиторы по математике, которые хотят получить несколько вариантов одной задачи 

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]** 
> Ниже приведено описание устройства, на котором продукт точно работает

* Операционная система: Windows 10 или macOS 12 и новее
* Веб-браузер: Браузер Google Chrome 150 или Opera 130 и новее
* Аппаратные требования: От 2 Гб оперативной памяти, 250мб свободного места, процессор Intel core i5 или аналог, встроенная видеокарта, стабильное подключение к Интернету
* Серверная часть: Python 3.9+, 1 Гб свободного дискового пространства

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Проект будет предоставлять следующие возможности:
* Аккаунт: регистрация, вход, восстановление пароля, профиль
* Автоматическая генерация заданий для разных уровней сложности
* Умная проверка ответов с распознаванием разных форм записи 
* Пошаговый анимированный реплей правильного решения: базовый график → сдвиг → растяжение → отражение → итог
* Адаптивная сложность заданий
* Режим «Песочница»: свободное управление ползунками параметров
* Система прогресса: XP, ранги, достижения, топ ошибок с кнопками «тренировать эту ошибку»
* Глубокие ссылки: любое задание/вариант доступно по URL с параметрами
* Подсказки трёх уровней для каждого задания
* Создание собственных тестовых вариантов

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

Анализ сервисов, которые максимально приближены к заданному функционалу:
* Desmos — отсутствует автогенерация заданий с проверкой, нет диагностики ошибок ученика; ученик должен сам придумать, что исследовать
*	GeoGebra — готовые файлы статичны, ответы не проверяются автоматически, ошибки не классифицируются
*	Khan Academy — обратная связь ограничена «верно/неверно» без классификации причины ошибки
  
**[ ИНСТРУМЕНТЫ РАЗРАБОТКИ, ИНФОРМАЦИЯ О БД ]**

* Python 3.9 / FastAPI / uvicorn – для разработки серверной части и REST API
* HTML5 / CSS3 / JavaScript – для разработки клиентской веб-версии и отрисовки графиков
* PostgreSQL через SQLAlchemy,  – для хранения профилей пользователей, сессий, попыток, вариантов заданий
* pytest / Pydantic – для тестирования и валидации данных
* PyCharm, VS Code, Git и GitHub
* Стиль кода: PEP8
